# Content Voices — система контент-голосов для ИИ-агентов

Набор навыков (skills) + три готовых профиля автора для генерации постов и статей **в конкретном голосе**, а не «в типовом ИИ-стиле». Работает на любом агенте, понимающем формат SKILL.md (OpenClaw, Claude, Codex и т.п.).

Профили собраны по реальным текстам автора: интервью + образцы → два файла на профиль (`about-me.md` + `voice.md`), которые навыки читают перед каждой генерацией.

## Состав

### Навыки (`skills/`)

| Навык | Что делает | Триггеры |
|---|---|---|
| `content-voice-builder` | Собирает новый голос: интервью + 3–5 образцов текста → профиль в `voices/<slug>/` | «собери мой голос», «паспорт голоса» |
| `tg-post-writer` | Пост для TG / статья для блога в выбранном голосе | «напиши пост», «пост AIpro про…» |
| `content-matrix` | 24–40 идей постов: рубрики × 8 форматов, на месяц вперёд | «матрица контента», «идеи для постов» |
| `hook-generator` | 6 вариантов зачина (хука) для темы | «хуки для темы…», «дай зачины» |

### Профили голосов (`voices/`)

| Ключ в запросе | Профиль | Площадки | Собран по |
|---|---|---|---|
| (default) | `supplychains` — Арт, автор @supplychains | TG-канал, блог supplychains.ru, Logistoria.com, Krossdok.ru | 4 постам канала |
| `AIpro` | `ai-pro` — директор по внедрению ИИ в производстве, логистике, офисе | LinkedIn, TG | 6 постам Bee Digitally |
| `CPO` | `cpo` — цифровой директор по обеспечению энерго-металлургического холдинга | LinkedIn, TG | 6 постам Bee Digitally (общий стиль с ai-pro, другой фокус) |

Ключи выбирают профиль прямо в запросе: «напиши пост **CPO** про управление запасами». Без ключа — default (supplychains) или уточняющий вопрос.

## Установка на другого агента

1. Скопировать папки из `skills/` в каталог навыков агента
2. Скопировать `voices/` в рабочую директорию агента (там, где навыки ищут файлы проекта)
3. Готово. Проверка: «напиши пост AIpro про предиктивное обслуживание»

Новый голос: «собери мой голос» → интервью в чате → `voices/<новый-slug>/`.

## Догенерация контента

- Черновики постов: `content-drafts/<slug>/YYYY-MM-DD-slug.md` (не входят в репо)
- Матрицы: `content-matrix-<slug>-YYYY-MM-DD.md` (не входят в репо)
